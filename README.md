# 실시간 지도 공유 웹사이트

프로젝트 시작일: 2026-07-23

## 목적

초대받은 사람만 입장할 수 있는 비공개 웹사이트에서, 여러 사용자가 세계 지도 위의 핀을 함께 추가하고 실시간으로 확인한다. 각 사용자는 자신의 화면을 독립적으로 움직이며, 지도 데이터와 채팅만 실시간으로 동기화한다.

## 현재 확정된 요구사항

- PC와 휴대폰 브라우저에서 모두 사용할 수 있는 반응형 웹사이트
- 초대받거나 승인된 사용자만 가입·접속 가능
- 세계 지도에 여러 사용자가 공동으로 핀을 추가·수정·삭제
- 핀의 변경 사항은 다른 참여자에게 즉시 반영
- 핀 두 개를 선택하여 거리 표시
  - 우선순위: 직선거리
  - 추후 확장: 자동차·도보 등 도로 기준 이동거리
- 방 또는 그룹 단위 실시간 채팅
- 사용자별로 다른 핀 색상
- 핀별 메모 등 기본 정보
- 개인별 핀 하이라이트와 즐겨찾기
- 사용자는 지도 화면을 각자 자유롭게 이동·확대할 수 있음
  - 다른 사용자의 화면 이동은 동기화하지 않음

## 위치 공유 원칙

- 위치 공유는 기본적으로 꺼져 있음
- 사이트 접속이나 방 입장만으로 위치를 수집하거나 공유하지 않음
- 사용자가 `내 위치 보내기` 또는 `위치 공유 시작`을 직접 누를 때에만 브라우저 위치 권한을 요청
- 허용 후에도 한 번만 핀으로 전송하거나, 사용자가 선택한 기간에만 실시간 공유하도록 제공
- 사용자는 언제든 위치 공유를 중지할 수 있어야 함
- 위치 공유를 사용하지 않아도 핀, 채팅, 거리 계산, 즐겨찾기 기능은 정상 사용 가능

## 권장 기술 구성 (초안)

| 영역 | 권장 선택 | 이유 |
| --- | --- | --- |
| 웹 화면 | Next.js + TypeScript | PC·모바일 대응, 유지보수 편의 |
| 로그인/DB/실시간 | Supabase | 인증, PostgreSQL DB, 실시간 동기화를 한 서비스에서 제공 |
| 지도 | Mapbox | 지도 표시·마커·거리 기능 구현이 편리함 |
| 대안 지도 | OpenStreetMap + Leaflet | 비용을 최소화하고 싶을 때 적합 |
| 배포 | Vercel | Next.js 배포가 간단함 |

참고: Google Maps도 가능하지만 API 키와 사용량 과금 관리가 필요하다. 초기 버전은 Mapbox 또는 OpenStreetMap 기반으로 검토한다.

## 핵심 데이터 구조 초안

- `users`: 사용자 프로필, 표시 이름, 핀 색상
- `spaces`: 지도 공유 공간(여행, 모임, 프로젝트 등)
- `space_members`: 공간별 멤버와 권한(소유자, 편집자, 보기 전용)
- `invitations`: 초대 링크 또는 이메일 초대 정보
- `pins`: 위치 좌표, 제목, 메모, 작성자, 색상, 생성·수정 시각
- `favorite_pins`: 사용자별 즐겨찾기 핀
- `pin_highlights`: 사용자별 하이라이트 설정
- `messages`: 공간별 채팅 메시지
- `location_shares`: 사용자 동의 기반의 일시적 위치 공유 상태 및 좌표

## 권한 초안

- 소유자: 공간 생성, 멤버 초대·제거, 모든 핀 관리
- 편집자: 핀 추가·수정·삭제, 채팅
- 보기 전용: 핀과 채팅 열람 (채팅 작성 권한은 추후 선택)

## 현재 구현 상태

첫 화면 프로토타입이 구현되어 있다.

실제 운영용 완성본은 `webapp` 폴더에 있다. Supabase 연결, 실행, 배포 방법은 `SETUP.md`를 따른다.

- `index.html`: 화면 구조
- `styles.css`: PC·모바일 반응형 스타일
- `app.js`: 지도 핀 추가, 핀 간 거리, 위치 권한 요청, 채팅 화면 동작

### 실행 방법

`index.html` 파일을 브라우저로 열면 된다. 지도 타일을 불러오려면 인터넷 연결이 필요하다.

현재 핀·채팅은 브라우저에서만 동작하는 프로토타입이다. 사용자 초대, 로그인, 다른 사람과의 실제 실시간 동기화는 다음 단계에서 Supabase 등의 서버를 연결하여 구현한다.
